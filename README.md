# 육삼레벨업

게이미피케이션 기반 학급경영 홈페이지예요. 학생은 출석·1인1역·칭찬 카드로 포인트와 능력치를 모으고, 레벨을 올리고, 보상 상점·꾸미기(프레임·아바타·칭호·펫)·던전에 참여해요. 선생님은 학생 관리, 카드 부여, 보상 승인, 누가기록, 게시판·쪽지 등을 한곳에서 관리해요.

- 데이터: Firebase (인증 + Firestore)
- 배포: GitHub Pages (`main` 브랜치의 파일이 그대로 사이트가 돼요, 빌드 과정 없음)

## 홈페이지 문 열기·닫기 (임시 폐쇄)

선생님 → 설정 → **🚪 홈페이지 문 열기·닫기**에서 버튼 하나로 닫고 열어요.
- 닫으면 접속 중인 학생 화면도 바로 뿌옇게 가려지고, 메뉴를 누를 수 없어요. 가운데에 안내 문구가 보여요.
- 안내 문구는 바꿀 수 있고, 저장하면 학생 화면에 바로 반영돼요.
- 닫혀 있는 동안 선생님 화면 맨 위에 "🔒 학생 화면 닫힘"이 보여요 (누르면 설정으로).
- 학생 데이터는 그대로이고, 다시 열면 바로 평소처럼 쓸 수 있어요.
- **`firestore.rules`를 콘솔에 붙여 넣어 두면** 문이 닫힌 동안 서버가 학생의 데이터 읽기·쓰기를 거절해요.
  새로고침하지 않은 옛날 화면이 켜져 있어도 포인트·상점·출석 등이 동작하지 않고, 학생이 몰래 문을 열 수도 없어요.
  (문이 열려 있을 때는 학생 요청마다 문 상태 문서를 한 번씩 더 읽어서 읽기 사용량이 조금 늘어요)
- 닫힌 동안 학생이 로그인하면 앱 대신 안내 화면만 보여요. 문을 열면 학생 화면이 알아서 새로고침돼요.

## 새 버전 자동 반영

켜 둔 화면은 5분마다, 그리고 화면을 다시 볼 때 `version.json`을 확인해서 새 버전이면 알아서 새로고침해요
(글을 입력하는 중이거나 창이 열려 있으면 다음에 해요). 그래서 고칠 때마다 `npm run bump`로 버전을 꼭 올려요.

## 데이터 백업

선생님으로 로그인 → 학생 관리 → **💾 전체 데이터 백업**. 모든 데이터를 `63levelup-backup-날짜.json` 파일로 내려받아요 (읽기만 하고 데이터는 바꾸지 않아요).

## 비밀번호와 보안 (2026-11 개편)

- 선생님 비밀번호는 데이터베이스에 저장하지 않아요. Firebase 로그인이 직접 확인해요.
- 학생 비밀번호 기록은 학생 문서가 아니라 **선생님만 읽을 수 있는 보관함**(`studentSecrets`)에 있어요.
- 학생 추가·비밀번호 변경·계정 점검은 "보조 로그인 창구"로 처리해서 선생님 로그인이 풀리지 않아요.
- 학생은 내 설정에서 비밀번호를 직접 바꿀 수 있고, 바꾼 비밀번호는 선생님 보관함에도 기록돼요.

### 보안 규칙 적용 순서 (한 번만)

1. 이 버전을 `main`에 합치고 사이트에서 새 버전이 뜨는지 확인 (학생 관리에 🧹 데이터 정리 버튼)
2. 학생 관리 → **💾 전체 데이터 백업**
3. 학생 관리 → **🧹 데이터 정리** → 검사하기 → 최소한 **🔐 비밀번호 기록 보호**를 체크하고 실행
4. Firebase 콘솔 → Firestore Database → **규칙(Rules)** 탭
   - 지금 들어 있는 규칙을 메모장에 복사해 두기 (되돌릴 때 필요)
   - 저장소의 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**
5. 선생님·학생 로그인이 잘 되는지 확인. 문제가 있으면 4번에서 복사해 둔 규칙으로 되돌려 게시

※ 백업 파일에는 학생 비밀번호 기록도 들어 있어요. 다른 곳에 올리거나 공유하지 마세요.

## 읽기 사용량 확인

사이트에서 F12(개발자 도구) → Console 에 `rsum()` 을 치면, 화면을 연 뒤 어디서 문서를 몇 개 읽었는지 많은 순서로 보여줘요 (Firestore 요금 기준, 실시간 구독 포함).

### 색인 2개를 만들면 더 줄어요 (선택)

아래 두 조회는 Firestore 복합 색인이 있으면 훨씬 적게 읽어요. 색인이 없으면 예전 방식으로 자동 대체돼서 오류는 나지 않아요.

| 화면 | 색인 | 줄어드는 양 |
|---|---|---|
| 학생 "내 능력치" 포인트 내역 | history: studentId ↑ + createdAt ↓ | 내 내역 전체 → 최근 10개 |
| 학생 "1인1역" | roleLogs: studentId ↑ + date ↑ | 반 전체 이번 주 기록 → 내 기록만 |

만드는 법: 학생으로 로그인해서 해당 화면을 연 뒤 F12 → Console 의 노란 경고에 나온 `https://console.firebase.google.com/...` 링크를 눌러 **색인 만들기** (몇 분 걸려요). 설정 내용은 `firestore.indexes.json` 에 있어요.

### 하루 사용량 한도 (Quota exceeded)

무료 요금제는 하루에 읽기 50,000번·쓰기 20,000번까지예요. 넘으면 **한국 시간 오후 5시**(미국 태평양 자정)에 풀릴 때까지 홈페이지 전체가 데이터를 못 불러와요 ("Quota exceeded" 메시지).
Firebase 콘솔 → Firestore Database → **사용량** 탭에서 날짜별 읽기·쓰기 양을 볼 수 있어요.

## 고치고 올리기

1. 파일 수정
2. `npm run bump` — 휴대폰·태블릿이 예전 파일을 쓰지 않도록 버전을 올려요
3. `npm test` — 파일끼리 주고받는 이름이 맞는지 확인해요 (처음 한 번 `npm install`)
4. 커밋 후 `main`에 합치면 GitHub Pages에 반영돼요

## 내 컴퓨터에서 열어 보기

`js/`가 모듈 방식이라 파일을 더블클릭하면 안 열려요. 저장소 폴더에서 아래를 실행하고 http://localhost:8000 으로 열어요.

```
python3 -m http.server 8000
```
